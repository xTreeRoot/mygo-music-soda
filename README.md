# Soda · MyGo Music 插件

浏览公开推荐歌单和音乐分类，播放服务端可用的完整歌曲，显示逐字歌词。公开内容无需登录或额外服务。当前版本为 **0.2.0**；扫码登录仍为实验功能。

## 安装

需要 **MyGo Music 0.1.18 或更新版本**。建议使用[最新官方版本](https://github.com/egoist/mygo-music/releases/latest)；0.1.18 起支持本插件使用的 AAC/M4A 音频。

1. 打开 MyGo Music → 设置 → 插件 → `+` → 从 GitHub 安装，输入 `sogud/mygo-music-soda`。
2. 也可从 [Releases](https://github.com/sogud/mygo-music-soda/releases) 下载 ZIP 后从本地安装。
3. 在来源选择器中选择「Soda」。

插件 ID 为 `soda`；源码目录和仓库名统一为 `mygo-music-soda`。已有旧 ID 安装不会自动迁移为 Soda，安装新版时应作为新插件处理。

## 功能与限制

- 公开推荐歌单、歌单歌曲、音乐分类和分类歌曲。
- 标准/高码率 AAC 音频，具体音质和可播放范围取决于服务端。
- 逐字歌词；没有逐字数据时返回原始歌词。
- **不支持搜索、私人歌单或会员专属内容。** 扫码登录尚待手机确认和会话恢复验收，不能视为已完成。
- 只提供试听片段的歌曲会提示在汽水音乐客户端播放，不绕过试听、登录或版权限制。
- 使用非官方公开接口，可能随服务端、地区或版权状态变化而失效。本插件与汽水音乐及其运营方无关联。

## 隐私与安全

登录会话由 MyGo Music 的插件私有存储保存；源码和安装包不包含账户 Cookie。插件向汽水音乐的内容及账号服务发送请求，音频由宿主播放，不提供额外代理服务。

扫码登录为实验功能，可能被账号服务拒绝；本版本不承诺登录成功。尚未完成最新官方桌面版的听音、暂停和跳转验收；可播放范围由服务端、地区和版权状态决定。

## 开发

无运行依赖或构建步骤。Node 和 Python 仅用于检查与打包：

```sh
npm run check
npm run pack
```
