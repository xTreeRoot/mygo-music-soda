# 汽水音乐 · MB 跨平台插件

基于 [sogud/mygo-music-soda](https://github.com/sogud/mygo-music-soda) 0.2.0 的 MIT 开源插件，当前版本 **0.3.5**。桌面、iOS 与 Android 使用同一份包。无需桌面辅助进程、Node、ffmpeg 或本机服务。

## 安装

在 MB → 我的 → 插件中从 GitHub 安装 `xTreeRoot/mygo-music-soda`，或者从 [Releases](https://github.com/xTreeRoot/mygo-music-soda/releases) 下载 ZIP 导入。插件 ID 保持 `soda`，音源名称为「汽水音乐」。宿主插件兼容版本需达到 0.1.21。

## 已实现能力

- 首页分为精选歌单和风格场景，使用平台封面和简介，查看更多打开完整列表。歌单曲目在点开时加载；推荐或分类单独失败，不挡住另一块内容。
- 标准/高码率 AAC，交给各端原生播放器。请求无损时选用可用的高码率 AAC，并返回真实音质。
- 播放地址只共享进行中的解析；旧地址失效后可重新向平台解析，歌词缓存不受影响。
- 逐字歌词；没有逐字数据时返回原始歌词。
- 试听片段会明确报错，避免把片段当成完整歌曲。
- 在 MB 内发起登录，使用汽水音乐 App 扫描专用登录二维码并确认。仅在平台核对账号后才写入本机插件数据；退出后停用，重新登录时先在线核对已存账号。
- 按官方 SodaMusic 3.7.0 登录组件核对：GET 取码、POST 确认，使用 API 本身作为回调，携带 CSRF 请求头，并构造 `/light/invoke/scan_login` 专用汽水二维码。扫码票据来自二维码 URL，轮询票据来自响应 token，两者分别保留。已移除公开参考里的固定安装 ID，账号与歌单读取继续使用 PC User-Agent。
- 请求被平台拒绝时显示所处阶段和平台数字错误码，不展示响应内容。
- iOS 切换到官方 App 确认后，扫码状态和账号资料的临时断线会用原二维码及临时会话最多恢复两次；取消后不再重试，验证失败不覆盖原账号。
- 登录后的个人库按自建、收藏、系统歌单分组；打开时按需加载曲目。平台向该会话返回账号所属的「喜欢」歌单时，也能在独立页面查看；没返回时会说明原因，不假装是空列表。

这版仍需每台设备单独登录，不会读取另一款桌面插件的会话，也不走节点同步。个人库只读：没有歌单编辑、点赞写入、收藏专辑、搜索、MV 或会员专属取流。如果平台要求额外安全验证（`2046`），请先在官方 App 处理后重试；本插件不会跳过验证。

## 登录协议核对

官网 `/download` 页面通过 `is.snssdk.com/service/settings/v3/` 的 `pc_download` 配置提供当前下载地址。已静态核对 [SodaMusic 3.7.0 官方资源包](https://lf-luna-release.qishui.com/obj/luna-release/3.7.0/452316191/SodaMusic-v3.7.0-official-win32_x64.tgz) 中 `main.asar/assets/renderer-Cpp7FaSO.js` 的登录组件：专用扫码入口及两个票据的使用方式、GET 取码、POST 确认、回调 `https://api.qishui.com`、确认表单字段，以及 WebInterfaceSdk Pro 版本 2.4.13。

`version_code` 的数字值 `30020100` 来自 MIT 公开参考 qishui-api，已在全新匿名会话实测取码及三次等待状态返回 HTTP 200、业务码 0。没有照搬参考的固定 iid，也没有虚构新设备注册信息。官方渲染脚本中的字符串版本 `3.7.0` 直接用于独立请求会被服务端以 4031 拒绝，因此不声称已复现官方客户端底层网络层的全部参数。只据协议事实独立实现适配，没有分发官方脚本。

旧版 0.3.4 的真实扫码仍返回错误码 7；0.3.5 修正专用二维码与会话参数后，完整授权和个人歌单**尚待手机验收**。匿名等待正常不能代替完成登录。

## 验证

可播放范围由平台、地区和版权状态决定；本插件不承诺每首歌都可用，与汽水音乐及其运营方无关联。个人库的新能力应以授权账号在目标宿主实际扫码、确认、打开私密歌单并核对曲目为准。

```sh
npm run check
npm test
npm run pack
```

Node 与 Python 仅用于开发测试和打包。运行时使用宿主网络与隔离存储；插件不会上传、导出或记录登录凭据。
