# 汽水音乐 · MB 跨平台插件

基于 [sogud/mygo-music-soda](https://github.com/sogud/mygo-music-soda) 0.2.0 的 MIT 开源插件，当前版本 **0.4.0**。桌面、iOS 与 Android 使用同一份包。无需桌面辅助进程、Node、ffmpeg 或本机服务。

## 安装

在 MB → 我的 → 插件中从 GitHub 安装 `xTreeRoot/mygo-music-soda`，或者从 [Releases](https://github.com/xTreeRoot/mygo-music-soda/releases) 下载 ZIP 导入。插件 ID 保持 `soda`，音源名称为「汽水音乐」。宿主插件兼容版本需达到 0.1.27。

## 已实现能力

- 首页分为精选歌单和风格场景，使用平台封面和简介，查看更多打开完整列表。歌单曲目在点开时加载；推荐或分类单独失败，不挡住另一块内容。
- 标准/高码率 AAC，交给各端原生播放器。请求无损时选用可用的高码率 AAC，并返回真实音质。
- 播放地址只共享进行中的解析；旧地址失效后可重新向平台解析，歌词缓存不受影响。
- 逐字歌词；没有逐字数据时返回原始歌词。
- 试听片段会明确报错，避免把片段当成完整歌曲。
- 在 MB 内的独立登录网页中使用汽水官方安全 SDK，浏览器自行维护本次 Cookie 与安全参数；使用汽水音乐 App 扫描专用二维码并确认。仅在平台核对账号后才写入本机插件数据；退出后停用，重新登录时先在线核对已存账号。
- 按官方 SodaMusic 3.7.0 登录组件核对：GET 取码、POST 确认，使用 API 本身作为回调，携带 CSRF 请求头，并构造 `/light/invoke/scan_login` 专用汽水二维码。扫码票据来自二维码 URL，轮询票据来自响应 token，两者分别保留。使用本机匿名注册得到的设备与安装 ID，账号与歌单读取继续使用 PC User-Agent。
- 请求被平台拒绝时显示所处阶段和平台数字错误码，不展示响应内容。
- 登录网页切到后台时暂停轮询，回到 MB 后继续同一会话；临时网络断线最多恢复两次，平台拒绝不自动重试。浏览器返回会话后再核对个人资料，验证失败或取消均不覆盖原账号。
- 登录后的个人库按自建、收藏、系统歌单分组；打开时按需加载曲目。平台向该会话返回账号所属的「喜欢」歌单时，也能在独立页面查看；没返回时会说明原因，不假装是空列表。

这版仍需每台设备单独登录，不会读取另一款桌面插件的会话，也不走节点同步。个人库只读：没有歌单编辑、点赞写入、收藏专辑、搜索、MV 或会员专属取流。若平台返回额外安全验证（`2046`），当前版本会明确显示错误码；这不等于验证已在官方 App 完成。

## 登录协议核对

官网 `/download` 页面通过 `is.snssdk.com/service/settings/v3/` 的 `pc_download` 配置提供当前下载地址。已静态核对 [SodaMusic 3.7.0 官方资源包](https://lf-luna-release.qishui.com/obj/luna-release/3.7.0/452316191/SodaMusic-v3.7.0-official-win32_x64.tgz) 中 `main.asar/assets/renderer-Cpp7FaSO.js` 的登录组件：专用扫码入口及两个票据的使用方式、GET 取码、POST 确认、回调 `https://api.qishui.com`、确认表单字段，以及 WebInterfaceSdk Pro 版本 2.4.13。

0.3.6 在取码前调用公开实现已有的 `/service/2/desktop/device_register/` 合同，为当前插件创建匿名实例。仅使用新生成的随机标识；不读取硬件序列号，不复制其他安装的 ID。平台返回的设备 ID 与安装 ID 保存在插件独立数据里，后续取码和每次确认均复用同一组 `device_id` / `did` / `install_id` / `iid`。取消时忽略迟到的注册结果，注册失败不进入扫码，也不自动重复注册。

匿名对照结果：仅带官方渲染层的字符串版本 `3.7.0` 而缺少注册 ID，会返回 4031；同一版本参数配合新注册实例，注册、取码及三次等待状态均返回 HTTP 200、业务码 0。0.3.5 使用数字兼容版本 `30020100` 可取码，但用户完成汽水专用扫码后仍返回 2156，因此不能视为已修复。0.3.6 已加入注册实例，但用户完成扫码后仍返回 7，完整授权没有修复。0.4.0 改为在隔离 WebKit 网页中加载官方安全 SDK，并在同一网页中完成取码和确认，避免手工搬运浏览器的安全会话。

0.4.0 的真实 WebKit 匿名验证中，官方 SDK 1.0.0.41 加载、`ttwid` 会话初始化、取码和三次等待扫码均正常。只记录状态码与资源域名，不记录二维码、账号、Cookie 或响应正文。完整授权和个人歌单**尚待手机验收**，匿名验证不能代替完成登录。

注册接口合同参考现有公开插件 [Guyu23/mygo-music-qishui](https://github.com/Guyu23/mygo-music-qishui)，并完成独立匿名请求验证；适配代码独立实现。官方客户端脚本仅用于核对协议事实，没有随插件分发。

## 验证

可播放范围由平台、地区和版权状态决定；本插件不承诺每首歌都可用，与汽水音乐及其运营方无关联。个人库的新能力应以授权账号在目标宿主实际扫码、确认、打开私密歌单并核对曲目为准。

```sh
npm run check
npm test
npm run pack
```

Node 与 Python 仅用于开发测试和打包。运行时使用宿主网络与隔离存储；插件不会上传、导出或记录登录凭据。
